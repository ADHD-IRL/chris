How To Use This Tool

No coding required. Here's how to add content to the site in 3 steps.

This tool generates code snippets that you paste into the site's index.html file. Think of it like filling out a form and getting a ready-to-use piece of text.

Step 1 — Fill in the form

Pick a content type from the left sidebar (Campaign Update, Story, Legal Doc, or Photo) and fill in the fields.

Step 2 — Copy the generated code

Click Generate Code, then click Copy to Clipboard.

Step 3 — Paste it into index.html
  1. Open index.html in a text editor (Notepad, TextEdit, VS Code, etc.).
  2. Press Ctrl+F (or Cmd+F on Mac) to search.
  3. Search for the array name shown in the instructions (e.g. CAMPAIGN_UPDATES).
  4. Click right after the opening [ bracket on that line.
  5. Paste the copied code, then add a comma after it if there are already items in the array.
  6. Save the file. Refresh the website.
Tips
  • Always add new items at the top of each array so they appear first on the site.
  • For Campaign Updates, the most recent date should go first.
  • Photo URLs must be public/shareable links — Google Drive "anyone with link" links work well.
  • If you're unsure, email WeThePeople@christopherleiphart.com for help.
